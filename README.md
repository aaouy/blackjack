# Blackjack - Command Line Game in C++

A simple command-line **Blackjack** game implemented in C++.  

---

## Features

- Standard Blackjack rules:
  - Hit, Stand, and Bust logic.
  - Dealer plays automatically.
  - Dealer hits on a soft 17.
- Deck of 52 cards.
- Shuffling and dealing.
- Score tracking per hand.
- Simple text-based interface.
  
---

## Build Instructions

### Using Makefile

```bash
# Compile the game
make

# Run the game
./build/blackjack

# Clean build artifacts
make clean
